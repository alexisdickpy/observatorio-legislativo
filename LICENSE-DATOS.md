## Origen

Los datos se obtienen de la API de Datos Abiertos Legislativos del Congreso Nacional de Paraguay
(<https://datosv2.congreso.gov.py>), publicada también bajo CC BY 4.0.

**Origen de los datos: Datos Abiertos Poder Legislativo.**

Cada archivo publicado indica la fecha de su última actualización. Los datos se reproducen tal como
los publica la fuente oficial; ante cualquier diferencia, prevalece la fuente oficial.

## Cómo citar

Al reutilizar estos datos, mencione:

1. Origen de los datos: Datos Abiertos Poder Legislativo.
2. Observatorio Legislativo (este repositorio), si usa los datos procesados o los indicadores calculados.
3. La fecha de actualización de los datos utilizados.

Este proyecto es independiente y no cuenta con el aval del Congreso Nacional. Quien reutilice los datos
no debe sugerir que el Congreso Nacional o este proyecto respaldan su uso.
